# Rapid Nova nurse staffing

React and Vite implementation of the supplied Rapid-Nova-Design reference.

## Development

```sh
npm install
npm run dev
```

## Production

```sh
npm run build
npm run preview
```

The original design is preserved in `Rapid-Nova-Design/`. The React sections and interactions are in `src/App.jsx`, with responsive styles in `src/styles.css`.

Job enquiries currently open email; no live job database or nurse portal is connected. Contact links use the email address supplied in the design.
